Aturan penyimpanan report:

Lokasi & nama file: Setiap kali ada report permintaan/update, harus disimpan di folder report/ dengan nama file report_<tanggal_hari_ini> (contoh: report_24-09-2026).
Kalau file report untuk tanggal hari ini SUDAH ADA:
→ Tidak perlu buat file baru. Cukup tambahkan report baru ke dalam file yang sudah ada, dipisahkan dengan tanda ====== dari report sebelumnya (sesuai contoh format yang dikasih).
Kalau file report untuk tanggal hari ini BELUM ADA:
→ Buat file baru report_<tanggal_hari_ini>, lalu tulis report di dalamnya.
Ini berlaku terus setiap hari — setiap tanggal baru otomatis akan punya file report sendiri (report_<tanggal>), dan report-report di hari yang sama akan menumpuk dalam satu file dengan pemisah ======.
