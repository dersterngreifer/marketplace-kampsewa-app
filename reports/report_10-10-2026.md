# Report Permintaan API Fitur Likes & History Komentar User
**Tanggal**: 10-10-2026

**Konteks Kendala & Fitur Baru:**
Tim frontend akan menambahkan fitur baru di halaman profil user (Profile), yaitu sebuah menu khusus yang berisi dua tab:
1. **Tab Produk Disukai (Likes):** Menampilkan daftar produk yang disukai (di-like) oleh user.
2. **Tab Riwayat Komentar (Feedback):** Menampilkan riwayat komentar/ulasan dan rating yang pernah diberikan user beserta produk yang dikomentari.

Untuk menunjang fitur ini, kami membutuhkan **dua API baru** dari tim backend karena saat ini API tersebut belum tersedia.

**Usulan Request API ke Tim Backend:**

1. **Endpoint Get Liked Products**
   - **Method:** `GET`
   - **URL/Endpoint:** `/api/user/likes` (atau sejenisnya)
   - **Header:** Auth Bearer Token (User yang sedang login)
   - **Fungsi:** Mengambil data list produk yang disukai oleh user.
   - **Response yang diharapkan:** Array of objects berisi data produk dasar seperti:
     - `id_product` (Wajib untuk navigasi ke detail produk)
     - `nama_product`
     - `gambar_product`
     - `harga`
     - `rating_rata_rata` (opsional jika ada)

2. **Endpoint Get Feedback/Komentar History**
   - **Method:** `GET`
   - **URL/Endpoint:** `/api/user/feedbacks` atau `/api/user/comments`
   - **Header:** Auth Bearer Token
   - **Fungsi:** Mengambil histori ulasan, komentar, dan rating yang pernah ditulis oleh user.
   - **Response yang diharapkan:** Array of objects berisi:
     - `id_feedback`
     - `id_product` (Wajib untuk navigasi ke detail produk)
     - `nama_product`
     - `gambar_product`
     - `rating_diberikan` (nilai bintang yang diberikan user)
     - `komentar` (teks ulasan)
     - `tanggal_ulasan`

Nantinya, apabila user menekan (tap) salah satu item dari daftar Like atau daftar Komentar ini, aplikasi mobile akan mengarahkannya langsung ke halaman detail produk tersebut. Mohon agar `id_product` selalu disertakan di setiap record.

# Report Permintaan API Fitur Ulasan (Rating & Feedback) Produk
**Tanggal**: 10-10-2026

**Konteks Kendala & Fitur Baru:**
Tim frontend membutuhkan API untuk mengirim ulasan produk (rating dan komentar) dari user serta mengambil daftar ulasan sebuah produk beserta informasi reviewer (nama dan foto) untuk ditampilkan di halaman detail produk.

**Detail API yang Dibutuhkan:**

1. **Endpoint Submit Review/Ulasan**
   - **Method:** `POST`
   - **URL/Endpoint:** `/api/produk/{id_produk}/review`
   - **Header:** `Authorization: Bearer <token>`
   - **Body/Payload:**
     ```json
     {
         "rating": 5,
         "ulasan": "Barang sangat bagus dan terawat."
     }
     ```
   - **Expected Response:**
     ```json
     {
         "message": "Ulasan berhasil dikirim."
     }
     ```

2. **Endpoint Get Product Reviews**
   - **Method:** `GET`
   - **URL/Endpoint:** `/api/produk/{id_produk}/reviews`
   - **Expected Response:**
     ```json
     {
         "message": "success",
         "data": [
             {
                 "id_rating": 1,
                 "id_user": 10,
                 "nama_user": "John Doe",
                 "foto_user": "http://localhost:8000/assets/image/customers/profile/user1.jpg",
                 "rating": 4,
                 "ulasan": "Sangat membantu untuk camping.",
                 "tanggal_ulasan": "2026-10-10 14:00:00"
             }
         ]
     }
     ```

# Report Permintaan API Fitur Upload Foto pada Ulasan (Review) Produk
**Tanggal**: 10-10-2026

**Konteks Kendala & Fitur Baru:**
Tim frontend telah mengimplementasikan UI interaktif untuk mengirimkan ulasan (rating, teks, dan foto) di halaman detail produk. Namun, API `POST /api/produk/{id_produk}/review` saat ini hanya menerima `rating` dan `ulasan` dalam format JSON, belum mendukung pengiriman file gambar/foto.

Kami membutuhkan dukungan untuk mengunggah foto ulasan agar pengguna dapat menyertakan bukti gambar saat memberikan ulasan.

**Detail Penyesuaian API yang Dibutuhkan:**

1. **Endpoint Submit Review/Ulasan (Diperbarui)**
   - **Method:** `POST`
   - **URL/Endpoint:** `/api/produk/{id_produk}/review`
   - **Header:** `Authorization: Bearer <token>`
   - **Content-Type:** `multipart/form-data` (Sebelumnya `application/json`)
   - **Body/Payload (Form Data):**
     - `rating`: integer (1-5, wajib)
     - `ulasan`: string (opsional/wajib)
     - `foto`: file gambar (opsional, max 2MB, format: jpg, jpeg, png)
   - **Response JSON (Success):**
     ```json
     {
         "message": "Ulasan berhasil dikirim."
     }
     ```

2. **Endpoint Get Product Reviews (Diperbarui)**
   - **Method:** `GET`
   - **URL/Endpoint:** `/api/produk/{id_produk}/reviews`
   - **Penyesuaian:** Tambahkan field `foto_ulasan` pada response data ulasan (bisa berupa string URL, atau array jika nanti mendukung banyak foto).
   - **Contoh Response JSON:**
     ```json
     {
         "message": "success",
         "data": [
             {
                 "id_rating": 1,
                 "id_user": 10,
                 "nama_user": "John Doe",
                 "foto_user": "http://localhost:8000/assets/image/customers/profile/user1.jpg",
                 "rating": 4,
                 "ulasan": "Sangat membantu untuk camping.",
                 "foto_ulasan": "http://localhost:8000/assets/image/reviews/review1.jpg", // Field baru
                 "tanggal_ulasan": "2026-10-10 14:00:00"
             }
         ]
     }
     ```

**Tindakan Sementara di Frontend:**
Saat ini, di aplikasi Flutter, kami telah membuatkan antarmuka untuk memilih foto. Namun, saat form dikirim, aplikasi hanya mengirimkan data `rating` dan `ulasan` saja, disertai pesan notifikasi kepada user bahwa fitur upload foto sedang dalam tahap pengembangan server. 

Mohon diinfokan apabila pembaruan API menjadi `multipart/form-data` ini sudah selesai agar kami bisa mengaktifkan integrasi pengiriman fotonya dari frontend.
