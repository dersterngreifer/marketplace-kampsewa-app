**Request API: Riwayat Transaksi (History Pesanan)**

**Deskripsi Kebutuhan:**
Aplikasi (frontend) saat ini di halaman `LayoutRiwayat` (RiwayatScreen) masih menggunakan data *dummy* (`DummyProductApiResponse`). Kami membutuhkan API sungguhan untuk memuat daftar riwayat pesanan (transaksi) pengguna berdasarkan status transaksinya (Belum Bayar, Pengambilan, Berlangsung, Selesai, Dibatalkan). Hal ini diperlukan karena setelah *user* melakukan *checkout*, pesanannya harus bisa dicek dan dibayar melalui tab "Belum Bayar" di halaman Riwayat.

**Endpoint yang Disarankan:**
`GET /api/transaksi/riwayat`

**Parameter (Query / Body):**
- `status` (string, opsional): Untuk melakukan *filter* riwayat berdasarkan status transaksi (misal: "Belum Bayar", "Pengambilan", "Berlangsung", "Selesai", "Dibatalkan"). Jika tidak dikirim, bisa mengembalikan semua data riwayat *user* yang sedang *login* (berdasarkan Bearer Token).

**Ekspektasi Response (JSON):**
```json
{
  "success": true,
  "message": "Berhasil mengambil riwayat transaksi",
  "data": [
    {
      "id_transaksi": 120,
      "nama_toko": "Eiger Store",
      "foto_produk": "url_gambar.jpg",
      "nama_produk": "Tenda Eiger",
      "variasi_warna": "Merah",
      "variasi_ukuran": "L",
      "qty": 2,
      "harga": 50000,
      "total_pesanan": 100000,
      "qty_produk_lain": 0,
      "rating": 0,
      "hari": 2,
      "status_transaksi": "Belum Bayar"
    }
  ]
}
```

**Catatan:**
Silakan sesuaikan format/nama variabel *response* dengan struktur tabel di *database* Anda. Setelah API ini siap, mohon kabari agar tim frontend dapat menghubungkan data dari API tersebut ke tampilan `LayoutRiwayat` dengan GetX API Service.

**Request API Update: Penambahan Field Metode Pembayaran pada API Riwayat**

**Deskripsi Kebutuhan:**
Pada endpoint riwayat pesanan (`GET /api/riwayat`), tim Frontend memerlukan tambahan data `metode_pembayaran` (misal: 'Transfer' atau 'COD') pada setiap *item* riwayat. Hal ini sangat penting agar aplikasi Mobile bisa membedakan pesanan mana yang bisa menampilkan tombol "Bayar Sekarang". Saat ini, karena Frontend tidak tahu metode pembayarannya, tombol "Bayar Sekarang" secara keliru muncul juga pada pesanan COD yang baru di-*checkout*.

**Perubahan yang Diminta:**
Tolong tambahkan `pembayaran_penyewaan.metode` ke dalam query select di fungsi `riwayat()`, lalu masukkan ke dalam balikan JSON data dengan nama field `metode`.

**Contoh Ekspektasi Response Baru:**
```json
{
  "success": true,
  "message": "Berhasil mengambil riwayat transaksi",
  "data": [
    {
      "id_transaksi": 120,
      "nama_toko": "Eiger Store",
      "...": "...",
      "status_transaksi": "Belum Bayar",
      "metode": "COD" // <-- FIELD BARU INI (Bisa 'COD' atau 'Transfer')
    }
  ]
}
```
